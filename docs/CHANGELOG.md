## M3: 풀기 전 화면 (2026-11-18)

- 6개 질문 정의(`src/core/questions.ts`), 진행 상태(`src/core/session.ts`), LLM 일감(`src/core/tasks.ts`: 채점·힌트·자유 질문 프롬프트와 응답 검사)
- 풀기 전 화면: 진행 막대(n/6), 통과한 질문은 한 줄로 접힘, 현재 질문만 큰 카드, 확인·힌트·건너뛰기, 틀리면 되묻는 한 줄, 자유 질문창(5번 제한)
- 단위 테스트 18개 추가(가짜 연결). 브라우저 확인 7개 항목 추가: 1→6번 진행, 틀림·힌트·건너뛰기, 힌트의 코드 블록 걸러짐, 채점 요청 횟수, 자유 질문 6번째에 LLM을 부르지 않음
- 확인 못 함: 실제 LLM이 채점·힌트를 지시대로 하는지(정답을 흘리지 않는지, 한 줄을 지키는지). 실제 키로만 확인 가능
- 아직 저장하지 않음(새로고침하면 진행이 사라짐) → M4

## M4: 풀이 기록 저장, 내 기록 보기, 글로 복사하기 (2026-11-18)

- 기록 스키마와 검증(`src/storage/schema.ts`): 풀이 기록, 개념 기록
- 저장·불러오기·통계·글 출력(`src/storage/records.ts`), 백그라운드 요청: 진행 상태 불러오기/저장, 기록 목록, 글
- 자동 저장, 새로고침해도 진행 중인 풀이를 이어 감
- 풀고 난 뒤 화면(M4 범위): 걸린 질문 6칸, "다 풀었어요"/"그만할래요", "이 풀이는 내 기록에 저장됐습니다", "내 기록 보기", "처음부터 다시 풀기"(새 기록)
- 내 기록 화면: 풀이 수·통과·진행 중(매번 계산), 풀이별 6칸, 글로 복사하기. 설정 화면에 "내 기록" 칸(보기, 글로 복사하기)
- 단위 테스트 22개 추가(지시서 예시 통과, 필드 누락·추가·열거값·날짜·6칸·id 실패, 진행 상태→기록 변환, 통계, 글). 브라우저 확인 12개 항목 추가
- 고친 버그: "글로 복사하기"가 `await` 뒤 이벤트 대상(null)을 써서 실패하던 것 (브라우저 테스트로 발견)
- 확인 못 함: 실제 코드트리 페이지에서 클립보드 복사가 막히지 않는지

## M5: 막혔을 때 화면 (2026-11-18)

- 실행 결과 감지(`src/core/runs.ts`, `src/sites/codetree/reader.ts`의 `watchRuns`): 화면 글자가 바뀔 때 결과 영역을 다시 읽어, 새 실행 결과가 뜰 때마다 한 번 센다. 오류 / 출력 불일치 / 통과를 따로 센다(`runs.total/errors/mismatches`가 기록에 들어감)
- 막혔을 때 화면(`src/ui/StuckView.tsx`):
  - 실행 결과: 오류는 오류 메시지 블록, 출력 불일치는 나의 출력과 정답을 나란히(다른 줄 빨간 표시, "n번째 줄부터 다릅니다"), 통과는 수행 시간·메모리와 "풀고 난 뒤로". 실행 횟수 표시, "화면에서 다시 읽기"
  - 힌트 사다리 4단계(질문 → 방향 → 코드 한 줄 → 정답): 한 단계씩, 지금 코드와 실행 결과를 같이 보냄. 3단계는 코드 한 줄만 남김. 정답은 한 번 더 묻고 기록에 "정답 봄"
  - 코드 리뷰 3항목(맞는가, 읽기 쉬운가, 더 단순한 길이 있는가): JSON으로 받아 "좋아요/살펴보기"와 한두 문장
  - 자유 질문창(풀기 전 화면과 같은 대화, 실행 결과를 같이 보냄)
- 오류·출력 불일치가 나면: 서랍이 닫혀 있으면 다음에 열 때 막혔을 때 화면, 열려 있으면 탭에 빨간 점
- 풀고 난 뒤 화면에 "실행 n번 · 오류 · 출력 다름 · 힌트 n단계까지 · 정답 봄" 한 줄
- 단위 테스트 24개 추가(표본 3종 인식, 새 실행 감지, 횟수, 줄 비교, 사다리, 3단계 한 줄, 리뷰 요청·응답, jsdom으로 지켜보기). 브라우저 확인 22개 항목 추가(가짜 페이지의 결과 영역을 바꿔 실행을 흉내 냄)
- 고친 버그: LLM 응답 JSON에서 ``` 울타리를 문자열 안까지 지워서, 채점 피드백·리뷰 코멘트 안의 코드 블록이 걸러지지 않고 코드 줄 일부가 남던 것 (리뷰 테스트로 발견, 채점에도 회귀 테스트 추가)
- 고친 것: 자유 질문 "보내기" 버튼 글자가 두 줄로 꺾이던 것
- 확인 못 함: 실제 코드트리에서 실행 결과가 화면에 어떤 순서로 그려지는지(그에 따라 실행 횟수가 맞게 세어지는지), 제출 및 채점 결과, 실제 LLM의 힌트·리뷰 품질
