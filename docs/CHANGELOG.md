## M2: LLM 연결부 + Claude API 키 + 설정 화면 (2026-11-18)

- 연결부 인터페이스(`src/llm/types.ts`), Claude API 연결(`src/llm/claude.ts`), 방식 고르기(`src/llm/registry.ts`), 테스트용 가짜 연결(`src/llm/fake.ts`)
- 키 보관(`src/storage/secrets.ts`), 백그라운드 요청: 연결 상태, 연결 확인, 키 저장
- 확장 설정 페이지: 연결 방식(Claude API 키만 켜짐, 나머지 "준비 중"), 키 입력·저장·지우기, 모델 선택, 연결 확인
- 서랍 설정 화면: 계정 연결 상태, 서랍 위치(왼쪽/오른쪽), 단축키 표시·바꾸기, 6개 질문 켜고 끄기
- 테스트 8개 추가(가짜 fetch로 요청 모양·오류 분류 확인). 브라우저 확인 7개 항목 추가(가짜 API 응답)
- 확인 못 함: 실제 키로 Claude API 호출(자동 테스트에서 실제 키를 쓰지 않음)

## M3: 풀기 전 화면 (2026-11-18)

- 6개 질문 정의(`src/core/questions.ts`), 진행 상태(`src/core/session.ts`), LLM 일감(`src/core/tasks.ts`: 채점·힌트·자유 질문 프롬프트와 응답 검사)
- 풀기 전 화면: 진행 막대(n/6), 통과한 질문은 한 줄로 접힘, 현재 질문만 큰 카드, 확인·힌트·건너뛰기, 틀리면 되묻는 한 줄, 자유 질문창(5번 제한)
- 단위 테스트 18개 추가(가짜 연결). 브라우저 확인 7개 항목 추가: 1→6번 진행, 틀림·힌트·건너뛰기, 힌트의 코드 블록 걸러짐, 채점 요청 횟수, 자유 질문 6번째에 LLM을 부르지 않음
- 확인 못 함: 실제 LLM이 채점·힌트를 지시대로 하는지(정답을 흘리지 않는지, 한 줄을 지키는지). 실제 키로만 확인 가능
- 아직 저장하지 않음(새로고침하면 진행이 사라짐) → M4

## M4: 풀이 기록 저장, 내 기록 보기, 글로 복사하기 (2026-11-18)

- 기록 스키마와 검증(`src/storage/schema.ts`): 풀이 기록, 개념 기록
- 저장·불러오기·통계·글 출력(`src/storage/records.ts`), 백그라운드 요청: 진행 상태 불러오기/저장, 기록 목록, 글
- 자동 저장, 새로고침해도 진행 중인 풀이를 이어 감
- 풀고 난 뒤 화면(M4 범위): 걸린 질문 6칸, "다 풀었어요"/"그만할래요", "이 풀이는 내 기록에 저장됐습니다", "내 기록 보기", "처음부터 다시 풀기"(새 기록)
- 내 기록 화면: 풀이 수·통과·진행 중(매번 계산), 풀이별 6칸, 글로 복사하기. 설정 화면에 "내 기록" 칸(보기, 글로 복사하기)
- 단위 테스트 22개 추가(지시서 예시 통과, 필드 누락·추가·열거값·날짜·6칸·id 실패, 진행 상태→기록 변환, 통계, 글). 브라우저 확인 12개 항목 추가
- 고친 버그: "글로 복사하기"가 `await` 뒤 이벤트 대상(null)을 써서 실패하던 것 (브라우저 테스트로 발견)
- 확인 못 함: 실제 코드트리 페이지에서 클립보드 복사가 막히지 않는지

## 수정: 설정 페이지 연결 확인 메시지 (2026-11-18)

- 증상: 키를 저장하기 전에 "연결 확인"을 누르면 "계정이 연결돼 있지 않습니다"가 뜨고, 키를 저장해 "연결됨"이 된 뒤에도 그 빨간 메시지가 남아 있었다(사용자 보고)
- 고침: 키를 저장하거나 지우면 이전 확인 결과를 지운다. 저장하면 바로 연결 확인을 한다. 입력창에 키가 있는 채로 "연결 확인"을 누르면 먼저 저장한다. 메시지는 버튼 줄 아래에 둔다(서랍 설정 화면도 같음)
- 브라우저 테스트에 같은 순서(확인 → 저장)를 넣어 확인
